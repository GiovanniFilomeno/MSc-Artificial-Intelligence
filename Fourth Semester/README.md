# Fourth Semester

The fourth semester is applied and systems-oriented: recommender systems, Python engineering, SAT solver implementation, statistics, life-science AI, and stochastic simulation.

| Course | Technical coverage |
| --- | --- |
| [Statistics for AI](<Statistics for AI>) | Applied statistical modelling and mathematical reporting. |
| [Learning from User-generated Data](<Learning from User-generated Data>) | Recommender systems, collaborative filtering, matrix factorization, ranking metrics, calibration, and content-based filtering. |
| [Programming in Python II](<Programming in Python II>) | Python engineering, plotting, pandas, web apps, PyTorch basics, and an air-quality prediction project. |
| [SAT Programming](SAT) | C++ SAT solver implementations, watched literals, CDCL-style solving, parsing, and PicoSAT integration. |
| [Artificial Intelligence in Life Science](<Artificial Intelligence in Life Science>) | Molecular generation and synthesis-prediction notebooks. |
| [Stochastic Simulation](<Stochastic Simulation>) | Pseudorandom generation, random variates, discrete-time processes, continuous-time processes, and SDE simulation. |
