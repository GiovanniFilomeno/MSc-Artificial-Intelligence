# Learning from User-generated Data

This course builds a recommender-system pipeline from simple baselines to collaborative filtering, matrix factorization, ranking evaluation, calibration, and content-based filtering.

The scaffold-heavy assignment notebooks are not included in the public portfolio. The table records curriculum coverage only.

| Assignment | Curriculum topic |
| --- | --- |
| Assignment 1 | Interaction matrices and popularity-based recommendation |
| Assignment 2 | Item-kNN and collaborative filtering |
| Assignment 3 | Matrix factorization |
| Assignment 4 | Offline evaluation with precision, recall, and nDCG |
| Assignment 5 | Popularity calibration and Jensen–Shannon divergence |
| Assignment 6 | Content-based filtering |
