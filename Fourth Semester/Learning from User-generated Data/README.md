# Learning from User-generated Data

This course builds a recommender-system pipeline from simple baselines to collaborative filtering, matrix factorization, ranking evaluation, calibration, and content-based filtering.

| Assignment | What it covers | Skills demonstrated | Repository contents |
| --- | --- | --- | --- |
| [Assignment 1](<Assignment 1>) | Interaction matrices and popularity-based recommendation. | Recommender-system basics, implicit feedback representation, baseline modelling. | `LUD25_ex01_[student-id]_Giovanni Filomeno.ipynb` |
| [Assignment 2](<Assignment 2>) | ItemKNN and collaborative filtering with implicit feedback. | Similarity computation, neighbourhood methods, recommendation scoring. | `LUD25_ex02_[student-id]_Giovanni Filomeno.ipynb` |
| [Assignment 3](<Assignment 3>) | Matrix factorization. | Latent-factor modelling, optimization, recommendation ranking. | `LUD25_ex03_[student-id]_Giovanni Filomeno.ipynb` |
| [Assignment 4](<Assignment 4>) | Evaluation with precision, recall, and nDCG. | Offline evaluation, ranking metrics, reusable recommender utilities. | `LUD25_ex04_[student-id]_Giovanni Filomeno.ipynb`, `rec.py` |
| [Assignment 5](<Assignment 5>) | Popularity-bias evaluation and calibration. | Popularity calibration, Jensen-Shannon divergence, fairness-aware evaluation. | `LUD25_ex05_[student-id]_Giovanni Filomeno.ipynb`, `rec.py` |
| [Assignment 6](<Assignment 6>) | Content-based filtering. | Item/content features, recommendation scoring, evaluation integration. | `LUD25_ex06_[student-id]_Giovanni Filomeno.ipynb`, `rec.py` |
