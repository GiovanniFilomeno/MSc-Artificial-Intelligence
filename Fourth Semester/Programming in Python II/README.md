# Programming in Python II

This course demonstrates practical Python engineering: functions and testing, plotting, pandas workflows, web applications, PyTorch basics, and an applied air-quality prediction project.

| Assignment | What it covers | Skills demonstrated | Repository contents |
| --- | --- | --- | --- |
| [Assignment 1](<Assignment 1>) | Advanced functions and unit tests. | Python functions, async/file utilities, unit testing, clean scripting. | `a1_ex*.py`, `a1_ex*_unittest.py` |
| [Assignment 2](<Assignment 2>) | Plotting and numerical visualization. | Matplotlib, NumPy, figure generation, visual communication. | `a2_ex*.py`, `a2_ex2_data.csv`, `ex*.png` |
| [Assignment 3](<Assignment 3>) | pandas-based data analysis. | Data cleaning, grouping, plotting, CSV/Excel workflows. | `a3_ex*.py`; the original datasets are not included |
| [Assignment 4](<Assignment 4>) | Web-based applications. | Python app structure and simple web interfaces. | `a4/a4_ex1/app.py`, `a4/a4_ex2/app.py`, `penguins.csv` |
| [Assignment 5](<Assignment 5>) | PyTorch basics. | Tensor operations, regression/classification models, MNIST data handling. | `a5_ex*.py` and generated regression/classification plots |
| [Assignment 6](<Assignment 6>) | Air-quality prediction with machine learning. | Data extraction, preprocessing, EDA, PyTorch regression, experiment comparison, Shiny dashboard development. | `a6_ex*.py`, `app.py`, cleaned CSV, and recorded search results; scaler and model weights are not included |
