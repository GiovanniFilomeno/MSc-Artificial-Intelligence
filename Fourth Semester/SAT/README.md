# SAT Programming

This course contains SAT programming exercises and a larger C++ solver project.

| Work | What it covers | Skills demonstrated | Repository contents |
| --- | --- | --- | --- |
| Exercises | Tseitin transformation, Limboole, BCP, DP methods, and Python-based SAT work. | SAT fundamentals, propositional logic transformations, solver reasoning. | Source notebooks/scripts where available; exported reports are omitted. |
| [Project](Project) | Multiple SAT solvers in C++17: recursive DPLL, watched literals, CDCL-style solving, parser logic, and PicoSAT integration. | Systems programming, algorithm implementation, Boolean satisfiability, solver benchmarking/debugging. | `main.cpp`, `solver*.cpp`, `parser.hpp`, `solver.hpp`, `test-formulas/` |
