# Stochastic Simulation

This course covers simulation of random systems, from pseudorandom generation to random variates, discrete-time processes, continuous-time processes, and SDE simulation.

| Exercise | What it covers | Skills demonstrated | Repository contents |
| --- | --- | --- | --- |
| [Exercise 1](<Exercise 1>) | Pseudorandom number generation and statistical testing. | Randomness testing, simulation setup, statistical reporting. | Source code where available; exported tutorial omitted. |
| [Exercise 2](<Exercise 2>) | Random variate generation methods. | Distribution sampling, acceptance-rejection reasoning, validation. | Source code where available; exported tutorial omitted. |
| [Exercise 3](<Exercise 3>) | Discrete-time stochastic processes. | Markov/process simulation, numerical experimentation. | Source code where available; exported tutorial omitted. |
| [Exercise 4](<Exercise 4>) | Continuous-time processes and SDE simulation. | Continuous stochastic modelling, simulation reporting, SDE intuition. | Source code where available; exported tutorial omitted. |
