# Biological Sequence Analysis

This course applies algorithmic thinking to biological sequence data.

| Assignment | What it covers | Skills demonstrated | Repository contents |
| --- | --- | --- | --- |

| [Assignment 2](<Assignment 2>) | Sequence comparison and substitution matrices. | Pairwise sequence reasoning, scoring functions, biological interpretation. | `ex3.py` |
| [Assignment 3](<Assignment 3>) | Gene-expression simulation and alignment-based scoring. | Simulation, sequence scoring, output validation, scientific reporting. | `ex5.py`, `test_sequences.fa`, `sample_output.txt`, `output.txt` |
