# Probabilistic Models

This course covers probabilistic reasoning and learning, with Bayesian networks, approximate inference, Gibbs sampling, structure learning, and hidden Markov models.

| Exercise | What it covers | Skills demonstrated | Repository contents |
| --- | --- | --- | --- |
| [Exercise 1](<Exercise 1>) | Basic probability, Bayes' theorem, joint distributions, conditional independence, and posterior queries. | Probabilistic reasoning, Bayesian updates, independence assumptions. | `[student-id]/Problem_1.ipynb`, `[student-id]/helpers.py` |
| [Exercise 2](<Exercise 2>) | Approximate inference and likelihood weighting. | Bayesian-network implementation, topological sorting, sampling-based inference. | `[student-id]/Problem_1.ipynb`, `[student-id]/bayesian_network.py` |
| [Exercise 3](<Exercise 3>) | Gibbs sampling and parameter learning. | MCMC reasoning, conditional distributions, maximum-likelihood estimates. | `[student-id]/Problem_1.ipynb`, `[student-id]/Problem_2.ipynb` |
| [Exercise 4](<Exercise 4>) | Structure learning for Bayesian networks. | Custom classes, graph-structure reasoning, score-based model analysis. | `[student-id]/Problem_1.ipynb`, `[student-id]/bayesian_network.py` |
| [Exercise 5](<Exercise 5>) | Hidden Markov models and sequence inference. | Forward/backward messages, HMM likelihoods, learning from observation sequences. | `[student-id]/Problem_1.ipynb`, `[student-id]/utils.py` |
