# Probabilistic Models

This course covers probabilistic reasoning and learning, with Bayesian networks, approximate inference, Gibbs sampling, structure learning, and hidden Markov models.

The scaffold-heavy primary exercise notebooks are omitted. Companion notebooks and student-authored Python utilities remain in the linked exercise folders.

| Exercise | What it covers | Skills demonstrated | Repository contents |
| --- | --- | --- | --- |
| [Exercise 1](<Exercise 1>) | Basic probability, Bayes' theorem, joint distributions, conditional independence, and posterior queries. | Probabilistic reasoning, Bayesian updates, independence assumptions. | `submission/Problem_2.ipynb`, `submission/Problem_3.ipynb`, `submission/Problem_4.ipynb`, `submission/helpers.py`, `submission/bn.svg` |
| [Exercise 2](<Exercise 2>) | Approximate inference and likelihood weighting. | Bayesian-network implementation, topological sorting, sampling-based inference. | `submission/BayesNet_Introduction.ipynb`, `submission/Problem_2.ipynb`, `submission/bayesian_network.py`, `submission/utils.py` |
| [Exercise 3](<Exercise 3>) | Gibbs sampling and parameter learning. | MCMC reasoning, conditional distributions, maximum-likelihood estimates. | `submission/BayesNet Introduction.ipynb`, `submission/Problem_2.ipynb`, `submission/bayesian_network.py`, `submission/utils.py` |
| [Exercise 4](<Exercise 4>) | Structure learning for Bayesian networks. | Custom classes, graph-structure reasoning, score-based model analysis. | `submission/BayesNet Introduction.ipynb`, `submission/bayesian_network.py`, `submission/utils.py` |
| [Exercise 5](<Exercise 5>) | Hidden Markov models and sequence inference. | Forward/backward messages, HMM likelihoods, learning from observation sequences. | `submission/Problem_2.ipynb`, `submission/utils.py`, `submission/hmm.svg` |
