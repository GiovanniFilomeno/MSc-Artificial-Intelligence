# Explainable AI

This course contains two portfolio-relevant team projects: one on projection-space exploration for trajectories and one on explaining CNN image classifiers.

| Project | What it covers | Skills demonstrated | Repository contents |
| --- | --- | --- | --- |
| [Projection Space Exploration](<1st Project>) | Compares reinforcement-learning trajectory data from Cliff Walking policies using projected state spaces and metadata-rich visualizations. | Dimensionality reduction, trajectory analysis, RL behaviour comparison, visual analytics. | Executable notebooks, utility code, and project README. |
| [Model Explanations](<2nd Project>) | Explains a CNN trained on CIFAR-10 using saliency maps, SHAP, and invertible concept-based explanations. | Model interpretability, CNN debugging, local/global explanations, concept analysis. | Explanation notebooks, PyTorch utilities, and project README. |
