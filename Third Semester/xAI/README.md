# Explainable AI

This course contains two portfolio-relevant team projects: one on projection-space exploration for trajectories and one on explaining CNN image classifiers.

| Project | What it covers | Skills demonstrated | Repository contents |
| --- | --- | --- | --- |
| [Projection Space Exploration](<1st Project>) | Compares reinforcement-learning trajectory data from Cliff Walking policies using projected state spaces and metadata-rich visualizations. | Dimensionality reduction, trajectory analysis, RL behaviour comparison, visual analytics. | Analysis notebooks, utility code, Conda/Docker environment files, and project README; generated Cliff Walking arrays are not included |
| [Model Explanations](<2nd Project>) | Studies a CIFAR-10 CNN with saliency maps, SHAP, concept-based explanations, and InstanceFlow data. | Model interpretability, CNN debugging, local/global explanations, concept analysis. | Explanation notebooks, PyTorch utilities, and representative figures; trained weights and large InstanceFlow JSON exports are not included |
