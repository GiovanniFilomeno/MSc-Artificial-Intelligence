# Third Semester

The third semester combines probabilistic modelling, computer vision, explainable AI, theory, and communication. Its strongest portfolio evidence is in the implemented notebooks, visual outputs, and reusable Python utilities.

| Course | Technical coverage |
| --- | --- |
| [Probabilistic Models](<Probabilistic Models>) | Bayesian networks, approximate inference, Gibbs sampling, parameter learning, structure learning, and HMMs. |
| [Computer Vision](<Computer Vision>) | Image processing, segmentation, optical flow, object tracking, detection, and 3D reconstruction. |
| [Explainable AI](xAI) | Projection-space exploration, RL trajectory visualization, saliency maps, SHAP, and concept-based model explanations. |
| [Computability and Complexity](<Computability and Complexity>) | Course context for NP-completeness reasoning and Karp reductions; written submissions are not included. |
| [Communicating in AI](<Communicating in AI>) | Course context for AI literacy and technical communication; written submissions are not included. |
