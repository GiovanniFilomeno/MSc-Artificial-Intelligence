# Third Semester

The third semester combines probabilistic modelling, computer vision, explainable AI, theory, and communication. It is one of the strongest semesters for portfolio storytelling because several assignments produce interpretable artifacts and reports.

| Course | Portfolio value |
| --- | --- |
| [Probabilistic Models](<Probabilistic Models>) | Bayesian networks, approximate inference, Gibbs sampling, parameter learning, structure learning, and HMMs. |
| [Computer Vision](<Computer Vision>) | Image processing, segmentation, optical flow, object tracking, detection, and 3D reconstruction. |
| [Explainable AI](xAI) | Projection-space exploration, RL trajectory visualization, saliency maps, SHAP, and concept-based model explanations. |
| [Computability and Complexity](<Computability and Complexity>) | NP-completeness reasoning and Karp reduction reporting. |
| [Communicating in AI](<Communicating in AI>) | AI literacy and technical communication. |
