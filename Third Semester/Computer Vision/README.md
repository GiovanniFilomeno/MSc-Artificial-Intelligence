# Computer Vision

This course covers the core computer-vision pipeline: image processing, feature extraction, segmentation, optical flow, tracking, detection, and 3D reconstruction.

| Assignment | What it covers | Skills demonstrated | Repository contents |
| --- | --- | --- | --- |
| [Assignment 1](<Assignment 1>) | Image processing basics. | Filtering, image representation, pixel-level transformations, visual analysis. | `Assignment-1-Image-Processing-Basics.ipynb` |
| [Assignment 2](<Assignment 2>) | Feature extraction and segmentation. | Image features, region analysis, segmentation workflows. | `Assignment-2-Feature Extraction and Segmentation.ipynb` |
| [Assignment 3](<Assignment 3>) | Optical flow, object tracking, and detection. | Motion estimation, tracking logic, detection pipelines. | `Assignment-3-Optical-Flow-Object-Tracking-and-Detection.ipynb` |
| [Assignment 4](<Assignment 4>) | 3D reconstruction. | Camera geometry, reconstruction reasoning, geometric computer vision. | `Assignment-4-3D-Reconstruction.ipynb` |
| [Bonus Assignment](<Bonus Assignment>) | Additional stack-processing and visualization experiments. | Experimental vision workflows, notebook-based debugging, image-stack analysis. | Sanitized notebook and visualization utilities; trained checkpoints are omitted. |
