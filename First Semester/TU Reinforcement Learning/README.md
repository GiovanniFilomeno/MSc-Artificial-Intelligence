# TU Reinforcement Learning

This course builds reinforcement-learning foundations from expectation and bandit problems to dynamic programming, Monte Carlo learning, temporal-difference learning, and policy gradients.

The introductory and bandit assignment notebooks were instructor-provided or scaffold-heavy submissions and are not included in the public portfolio. The table below lists the retained student-code exercises.

| Assignment | What it covers | Skills demonstrated | Repository contents |
| --- | --- | --- | --- |
| [Assignment 2](<Assignment 2>) | Dynamic programming in a grid-world style environment. | Value iteration, policy evaluation, environment modelling. | `fishlake.py`, `testing.py` |
| [Assignment 3](<Assignment 3>) | Monte Carlo methods with Blackjack and updated grid-world utilities. | Episode sampling, returns, Monte Carlo control, policy evaluation. | `blackjack_convenience.py`, `fishlake_updated.py`, `testing.py` |
| [Assignment 4](<Assignment 4>) | Temporal-difference learning and custom grid-world environments. | TD updates, Q-learning/SARSA-style reasoning, Gym environment structure. | `gym_gridworlds/`, `testing.py` |
| [Assignment 5](<Assignment 5>) | Policy-gradient methods. | Gradient estimators, reward curves, baseline comparisons. | `testing.py`, expected-output images, and reward plots |
