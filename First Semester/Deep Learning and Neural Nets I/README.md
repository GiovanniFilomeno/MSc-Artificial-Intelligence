# Deep Learning and Neural Nets I

This course documents the foundations of neural-network implementation, from regression and modular layers to CNNs, adaptive optimization, and regularization.

| Assignment | What it covers | Skills demonstrated | Repository contents |
| --- | --- | --- | --- |
| [Assignment 1](<Assignment 1>) | Regression, NumPy-based modelling, training utilities, and testing helpers. | Numerical programming, loss functions, gradient-based learning, reproducible testing. | `Assignment1_[student-id].ipynb`, `utils.py`, `testing.py`, `data.py` |
| [Assignment 2](<Assignment 2>) | Multilayer perceptrons and a small module system for neural networks. | Activation functions, backpropagation, modular design, forward/backward passes. | `Assignment2_[student-id].ipynb` |
| [Assignment 3](<Assignment 3>) | Convolutional neural networks and image classification concepts. | Cross-correlation, convolution, CNN architecture reasoning, feature extraction. | `Assignment3_[student-id].ipynb` |
| [Assignment 4](<Assignment 4>) | Adaptive optimization and stochastic gradient methods. | SGD variants, optimizer implementation, optimization diagnostics. | `Assignment4_[student-id].ipynb`, `modules_implemented.py` |
| [Assignment 5](<Assignment 5>) | Regularization, initialization, and normalization. | Dropout, initialization strategy, normalization layers, generalization control. | `Assignment5_[student-id].ipynb` |
