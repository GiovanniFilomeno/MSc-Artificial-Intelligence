# Deep Learning and Neural Nets I

This course covered neural-network foundations, from regression and modular layers to CNNs, adaptive optimization, and regularization.

The instructor-authored assignment notebooks carried explicit redistribution restrictions and are not included in the public portfolio. Selected student-written support code remains in [Assignment 1](<Assignment 1>) and [Assignment 4](<Assignment 4>); the table records the full curriculum sequence.

| Assignment | Curriculum topic |
| --- | --- |
| Assignment 1 | Regression and neural-network utilities |
| Assignment 2 | Multilayer perceptrons and modular forward/backward passes |
| Assignment 3 | Convolutional neural networks and image classification |
| Assignment 4 | Adaptive optimization and stochastic-gradient methods |
| Assignment 5 | Regularization, initialization, and normalization |
