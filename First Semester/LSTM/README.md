# LSTM

This course focuses on sequence modelling, starting with fully recurrent networks and ending with LSTMs and transformer attention in PyTorch.

| Assignment | What it covers | Skills demonstrated | Repository contents |
| --- | --- | --- | --- |
| [A1 Assignment](<A1 Assignment>) | Fully recurrent networks and numerical stability of binary cross-entropy. | Recurrent computation, stable loss implementation, NumPy/SciPy experimentation. | `A1_Giovanni Filomeno_[student-id].ipynb` |
| [A2 Assignment](<A2 Assignment>) | Training a fully recurrent network with generated sequence data. | Backpropagation through time, gradient derivation, sequence-data generation. | `A2_Giovanni Filomeno_[student-id].ipynb` |
| [A3 Assignment](<A3 Assignment>) | Character-level text processing with LSTMs in PyTorch. | Character encoding, custom datasets, PyTorch recurrent models, language modelling. | `A3_Giovanni Filomeno_[student-id].ipynb` |
| [A4 Assignment](<A4 Assignment>) | Transformer training in PyTorch. | Causal self-attention, multi-head attention, sequence batching, transformer components. | `A4_Giovanni Filomeno_[student-id].ipynb` |
