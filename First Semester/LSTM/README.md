# LSTM

This course focused on sequence modelling, starting with fully recurrent networks and ending with LSTMs and transformer attention in PyTorch.

The instructor-authored assignment notebooks carried explicit redistribution restrictions and are not included in the public portfolio. The table records curriculum coverage only.

| Assignment | Curriculum topic |
| --- | --- |
| Assignment 1 | Fully recurrent networks and numerically stable binary cross-entropy |
| Assignment 2 | Backpropagation through time and recurrent-network training |
| Assignment 3 | Character-level language modelling with LSTMs |
| Assignment 4 | Causal and multi-head attention in transformers |
