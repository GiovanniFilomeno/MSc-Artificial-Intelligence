# Machine Learning - Supervised Learning

This course covered classical supervised-learning methods and evaluation, moving from k-nearest neighbors to SVMs, trees, ensembles, logistic regression, neural networks, and CNNs.

The instructor-authored assignment notebooks carried explicit redistribution restrictions and are not included in the public portfolio. The table records curriculum coverage only.

| Assignment 0 | Mathematical notation and scientific writing |
| Assignment 1 | k-nearest neighbors |
| Assignment 2 | Gaussian classifiers, bias-variance decomposition, and evaluation metrics |
| Assignment 3 | Constrained optimization and support vector machines |
| Assignment 4 | Decision trees |
| Assignment 5 | Ensemble methods |
| Assignment 6 | Logistic regression |
| Assignment 7 | Feed-forward neural networks and PyTorch fundamentals |
| Assignment 8 | Convolutional neural networks |
