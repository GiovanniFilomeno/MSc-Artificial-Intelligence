# Machine Learning - Unsupervised Learning

This course covered statistical unsupervised-learning methods, from estimation theory to projection, decomposition, and latent-variable methods.

The instructor-authored assignment notebooks carried explicit redistribution restrictions and are not included in the public portfolio. The table records curriculum coverage only.

| Assignment 2 | Maximum-likelihood estimation |

| Assignment 5 | Independent component analysis |
| Assignment 6 | Factor analysis |
