# Deep Learning II

This course extended deep learning into PyTorch workflows, efficient vision networks, generative modelling, adversarial robustness, normalizing flows, and Bayesian deep learning.

The instructor-authored assignment notebooks carried explicit redistribution restrictions and are not included in the public portfolio. The table records curriculum coverage only.

| Assignment | Curriculum topic |
| --- | --- |
| Assignment 1 | PyTorch framework fundamentals and training loops |
| Assignment 2 | Vision networks and efficient training |
| Assignment 3 | Experiment monitoring, hyperparameters, and efficient CNNs |
| Assignment 4 | Transposed convolutions and variational autoencoders |
| Assignment 5 | Adversarial attacks and robustness |
| Assignment 6 | Normalizing flows and invertible transformations |
| Assignment 7 | Bayesian deep learning and uncertainty |
