# Deep Learning II

This course extends deep learning into modern PyTorch workflows, efficient vision networks, generative modelling, adversarial robustness, normalizing flows, and Bayesian deep learning.

| Assignment | What it covers | Skills demonstrated | Repository contents |
| --- | --- | --- | --- |
| [Assignment 1](<Assignment 1>) | Deep learning with PyTorch and framework basics. | Tensor operations, model definition, training loops, framework comparison. | `Assignment1_[student-id].ipynb` |
| [Assignment 2](<Assignment 2>) | Vision networks and fast training. | LeNet/AlexNet-style reasoning, CNN training, performance-aware workflows. | `Assignment2_[student-id].ipynb` |
| [Assignment 3](<Assignment 3>) | Monitoring, hyperparameters, and efficient CNNs. | Experiment tracking, hyperparameter tuning, TensorBoard-style outputs. | `Assignment3_[student-id].ipynb`, `run/` |
| [Assignment 4](<Assignment 4>) | Reversing convolutions and variational autoencoders. | Transposed convolutions, autoencoders, latent-variable modelling. | `Assignment4_[student-id].ipynb` |
| [Assignment 5](<Assignment 5>) | Adversarial training. | Projected gradient attacks, robustness evaluation, model stress testing. | Sanitized notebook; trained checkpoints are intentionally omitted. |
| [Assignment 6](<Assignment 6>) | Normalizing flows. | Invertible transformations, Jacobian reasoning, density modelling. | `Assignment6_[student-id].ipynb` |
| [Assignment 7](<Assignment 7>) | Bayesian deep learning. | Gaussian processes, uncertainty, Bayesian modelling concepts. | `Assignment7_[student-id].ipynb` |
