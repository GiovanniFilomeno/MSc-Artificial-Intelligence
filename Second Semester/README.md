# Second Semester

The second semester moves from foundations to more advanced modelling: PyTorch deep learning, deep reinforcement learning, unsupervised learning, theoretical machine learning, stochastic simulation, knowledge representation, and human-centered AI.

| Course | Portfolio value |
| --- | --- |
| [Deep Learning II](<Deep Learning II>) | Efficient CNNs, monitoring, VAEs, adversarial training, normalizing flows, and Bayesian deep learning. |
| [Deep Reinforcement Learning](<Deep Reinforcement>) | Imitation learning, DQN for Minigrid, PPO, evaluation scripts, and model artifacts. |
| [Machine Learning - Unsupervised Learning](<Machine Learning - Unsupervised Learning>) | Estimation, PCA, kernel PCA, ICA, factor analysis, scaling, and projection methods. |
| [Theoretical Concepts in ML](<Theoretical Concepts in ML>) | Probability, estimation theory, probabilistic PCA, VAEs, learning theory, neural ODEs, and diffusion models. |
| [Stochastic Simulation](<Stochastic Simulation>) | Random variate generation, Markov chains, Black-Scholes simulation, Monte Carlo integration, and simulation reporting. |
| [Knowledge Representation](<Knowledge Representation>) | Prolog, logic programming, inductive logic programming, Aleph, and Popper. |
| [Robopsychology](Robopsycology) | Paper reviews and written analysis on trust, explainable AI, and human-robot interaction. |
