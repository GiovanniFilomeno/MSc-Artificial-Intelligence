# Knowledge Representation

This course explores symbolic AI, logic programming, and inductive logic programming tools.

| Project | What it covers | Skills demonstrated | Repository contents |
| --- | --- | --- | --- |
| [First Project](<First Project>) | Prolog-based knowledge representation and reasoning. | Logic programming, rule modelling, query construction. | `First_exercise.ipynb`, `ex1.pl`, `ex2.pl`, `ex3.pl`, `test.pl` |
| [Second Assignment](<Second Assignment>) | Inductive logic programming with Aleph and Popper. | Rule learning, background knowledge design, logic-based ML workflows. | Aleph/Popper source folders, experiment code, and result files |

Note: the public copy keeps the assignment scripts and example files. External ILP runtimes such as Aleph should be installed or supplied locally when re-running the experiments.
