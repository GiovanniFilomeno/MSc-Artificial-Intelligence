# Stochastic Simulation

This course focuses on simulation methods for stochastic systems and numerical experiments.

| Topic | What it covers | Skills demonstrated | Repository contents |
| --- | --- | --- | --- |
| Pseudorandom generation | RANDU-style generators and statistical testing. | Randomness diagnostics, simulation setup, statistical interpretation. | R simulation code and portfolio summary. |
| Random variate generation | Acceptance-rejection and Box-Muller methods. | Distribution sampling, algorithmic simulation, validation. | R simulation code and portfolio summary. |
| Markov chains and finance simulation | Markov chains and Black-Scholes-style numerical illustration. | Stochastic-process reasoning, path simulation, Monte Carlo analysis. | R simulation code and portfolio summary. |
| Monte Carlo integration | Numerical integration through sampling. | Error analysis, convergence, empirical validation. | R simulation code and portfolio summary. |
