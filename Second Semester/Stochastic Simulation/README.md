# Stochastic Simulation

This course focuses on simulation methods for stochastic systems and numerical experiments.

| Topic | What it covers | Skills demonstrated | Repository contents |
| --- | --- | --- | --- |
| Pseudorandom generation | RANDU-style generators and statistical testing. | Randomness diagnostics, simulation setup, statistical interpretation. | `Exercise1.R` |
| Random variate generation | Acceptance-rejection and Box-Muller methods. | Distribution sampling, algorithmic simulation, validation. | `Exercise2.R` |
| Markov chains and finance simulation | Markov chains and Black-Scholes-style numerical illustration. | Stochastic-process reasoning, path simulation, Monte Carlo analysis. | `Exercise3.R`, `Exercise4.R` |
| Monte Carlo integration | Numerical integration through sampling. | Error analysis, convergence, empirical validation. | `Exercise5.R`, `simulation-code.R` |
